# День 11 — явная модель памяти ассистента

MrKai разделяет память на три независимых слоя и показывает, что именно
попадёт в следующий запрос модели:

- **краткосрочная** (short) — важные временные факты текущего диалога;
- **рабочая** (working) — цель, ограничения и данные текущей задачи;
- **долговременная** (long) — профиль пользователя, принятые решения и
  устойчивые знания.

После каждого успешного ответа отдельный вызов модели анализирует пару
«сообщение пользователя + ответ», выделяет атомарные важные факты и возвращает
структурированный patch для short, working и long. Полные сообщения хранятся
только в оперативном буфере текущего запуска (до 12 сообщений) для связности
диалога и никогда не записываются в файлы памяти. API-ключи, токены, пароли и
другие учётные данные отбрасываются.

При загрузке или обновлении веб-страницы временный transcript очищается. Все
извлечённые short/working/long факты при этом остаются на месте и продолжают
участвовать в следующих ответах.

Автоматический extractor умеет добавлять, обновлять и удалять устаревшие факты.
Команды /remember и форма остаются способом вручную исправить классификацию.
Автоизвлечение выполняет один дополнительный непотоковый LLM-запрос на каждый
успешный ответ.

## Ограниченный доступ к интернету

У модели нет общего браузера и возможности открыть произвольный URL. Для двух
типов актуальных запросов агент предоставляет узкие read-only инструменты:

- погода — только JSON-прогноз с `https://wttr.in`;
- технические статьи — только публичный список с
  `https://dev.to/api/articles` по одному DEV Community tag.

Например: «Какая погода завтра в Москве?» или «Посоветуй свежие статьи про
Golang». Модель извлекает из вопроса только название места либо безопасный тег,
а URL строит само приложение. Разрешены только HTTPS, точные хосты и заданные
пути; редиректы отключены, ответы ограничены по размеру, ссылки из выдачи статей
повторно проверяются на домен `dev.to`. В чат передаются нормализованные поля, а
не содержимое произвольной страницы. Источник использованного инструмента виден
в терминале и веб-интерфейсе.

Для запроса погоды или статей выполняется один дополнительный непотоковый
LLM-вызов, определяющий город или тег. Если источник недоступен, агент получает
явную инструкцию не выдумывать актуальные данные и ссылки.

## Установка и запуск

Нужны Go 1.21+ и ключ DeepSeek в окружении.

~~~sh
cd aiac9/d11
chmod +x mrkai
mkdir -p "$HOME/.local/bin"
ln -sf "$PWD/mrkai" "$HOME/.local/bin/mrkai"
export PATH="$HOME/.local/bin:$PATH"
export DEEPSEEK_API_KEY="<ваш-ключ>"
mrkai
~~~

Из каталога дня также можно запустить ./mrkai. Без аргументов всегда
открывается основной терминальный агент.

## Терминальные команды

~~~text
/remember short draft проверить формулировку
/remember working deadline пятница
/remember long profile.language русский
/memory
/forget working deadline
/clear short
/clear working
/clear long
/clear all
/reset
/info
/exit
~~~

У /remember явно указаны слой, ключ и значение. Значение может содержать
пробелы. /memory [short|working|long] показывает один или все слои.

В интерактивном терминале ввод / открывает меню команд. Продолжайте печатать для
фильтрации; ↑/↓ выбирают вариант, Tab дополняет, Enter подтверждает, Esc закрывает
меню. Когда меню закрыто, ↑/↓ листают историю сообщений и команд. Ctrl+U и
Ctrl+Backspace очищают строку. В перенаправленном вводе остаётся обычный
построчный режим.

## Веб-интерфейс

~~~sh
mrkai web
~~~

Откройте http://localhost:8080. Слева расположен чат, справа — три отдельных
окна памяти и форма «Сохранить явно». У каждой записи есть кнопка удаления.
После ответа автоматически извлечённые факты сразу появляются в нужных окнах и
используются со следующего сообщения. Ответы отображают Markdown: заголовки,
списки, цитаты, ссылки, выделение, inline-код и fenced code blocks. HTML из
ответа не исполняется.

Поле веб-чата поддерживает такое же slash-меню: / показывает команды, ввод
фильтрует их, ↑/↓ меняют выбор, Tab дополняет, Enter выполняет готовую команду,
Esc закрывает меню. Команды обрабатываются отдельным HTTP handler и не
отправляются модели; ↑/↓ вне меню возвращают историю ввода.

## Конфигурация

- DEEPSEEK_API_KEY — обязательный ключ;
- DEEPSEEK_MODEL — модель, по умолчанию deepseek-chat;
- DEEPSEEK_BASE_URL — OpenAI-совместимый endpoint DeepSeek;
- AGENT_SYSTEM_PROMPT — системная инструкция;
- DATA_DIR — каталог данных, по умолчанию ./data;
- WEB_ADDR — адрес веб-сервера, по умолчанию :8080;
- WEATHER_ENABLED — `1` по умолчанию, `0` отключает запросы к wttr.in;
- ARTICLES_ENABLED — `1` по умолчанию, `0` отключает запросы к dev.to.

Слои хранятся физически раздельно в файлах short-term.json, working.json и
long-term.json. Файлы создаются атомарно с правами 0600. Записи памяти
маркируются в запросе как пользовательские данные, а не инструкции.
Старый short-term.json мигрирует автоматически: сообщения удаляются, а ручные
заметки сохраняются как факты.
