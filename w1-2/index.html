DeepSeek API · один и тот же запрос с разным уровнем контроля ответа: формат, длина, завершение

Параметры режимов
Без ограничений
Базовый промпт без параметров — контрольная точка.
Формат ответа
К промпту дописывается описание формата, response_format гарантирует валидный JSON.
Лимит длины
max_tokens обрывает ответ на заданном объёме.
Стоп-последовательность
stop останавливает генерацию на первом вхождении.
Один и тот же промпт отправляется в 4 режимах: без ограничений, с явным описанием формата, с лимитом длины (max_tokens), со стоп-последовательностью (stop).
