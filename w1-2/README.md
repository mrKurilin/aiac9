# w1-2 · LLM Playground (DeepSeek) — контроль формата ответа

Минимальный пример на Go: один и тот же запрос к LLM через API с разным уровнем контроля ответа — описание формата, лимит длины, условие завершения.

## Запуск

```bash
export DEEPSEEK_API_KEY=sk-...
go run .
```

Откройте http://localhost:8080

## Что умеет

- Отправляет один и тот же промпт в DeepSeek API (модель `deepseek-chat`, OpenAI-совместимый формат) в **4 режимах**:
  - **Без ограничений** — базовый промпт, доп. параметры не задаются;
  - **Формат ответа** — к промпту добавляется явное описание формата;
  - **Лимит длины** — задаётся `max_tokens`, генерация обрывается по лимиту;
  - **Стоп-последовательность** — задаётся `stop`, генерация останавливается на первом вхождении.
- **Таблица сравнения**: столбцы — режимы, строки — отправленный промпт, параметры, ответ и метаданные (`finish_reason`, число токенов).

## Настройки

Каждый режим — карточка с описанием параметра и редактируемым JSON:

| Режим                   | Описание                                                   | Дефолт в JSON (редактируется)                 |
|-------------------------|------------------------------------------------------------|-----------------------------------------------|
| Без ограничений         | базовый промпт без параметров — контрольная точка          | `{}`                                          |
| Формат ответа           | к промпту дописывается описание формата; `response_format` | `{"response_format": {"type":"json_object"}}` |
| Лимит длины             | `max_tokens` обрывает ответ на заданном объёме             | `{"max_tokens": 60}`                          |
| Стоп-последовательность | `stop` останавливает генерацию на первом вхождении         | `{"stop": ["."]}`                             |

Поля JSON правите свободно: добавляйте любые параметры (например, `{"temperature": 0}`), очистите поле — режим без параметров. Для «Формата» есть отдельное поле «Описание формата» — текст дописывается к промпту.

## API сервера

- `GET /` — веб-интерфейс
- `POST /api/complete` — тело `{"prompt": "...", "config": {"format": "..."}, "params": {"max_tokens": 60}}`; `config.format` дописывается к промпту; `params` — произвольные параметры, мержатся поверх сформированного запроса; ответ `{"content": "...", "finish_reason": "...", "prompt_tokens": N, "completion_tokens": N, "total_tokens": N}` или `{"error": "..."}`
