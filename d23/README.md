# День 23 — reranking и фильтрация RAG

`mrkai` строит локальный индекс Markdown и текстовых документов. В улучшенном RAG сначала берёт top-K кандидатов по cosine similarity, затем переформулирует запрос через модель и отсекает нерелевантные фрагменты по порогу. Команда сравнения показывает ответ и источники до и после этого этапа.

## Установка и запуск

Нужен Go 1.21+. В каталоге `aiac9/d23`:

```sh
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
```

Для ответов и rewrite задайте `DEEPSEEK_API_KEY`. Дополнительно можно изменить `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL` и `DATA_DIR`. Ключ задаётся только в окружении и не выводится в терминал.

## Работа с RAG

```text
/index build knowledge
/rag on
/rag config
Сколько дней PTO?
/rag compare Сколько дней PTO?
```

`/rag top N` настраивает число кандидатов до фильтра, `/rag final N` — итоговое число фрагментов, `/rag threshold 0..1` — минимальную similarity, `/rag rewrite on|off` — rewrite запроса. `/rag compare ВОПРОС` всегда сопоставляет базовый поиск без rewrite/фильтра с улучшенным режимом. Интерактивный интерфейс повторяет d22: полноэкранный журнал, фиксированная строка ввода, история, выбор стрелками и Tab-автодополнение команд.

Команды: `/index build [КАТАЛОГ]`, `/index status`, `/rag on|off|status|config`, `/rag threshold`, `/rag top`, `/rag final`, `/rag rewrite`, `/rag compare`, `/help`, `/exit`.

`/reset` и `/clear` начинают новый диалог: удаляют историю сообщений модели и очищают экран. Индекс, документы, режим RAG и параметры фильтрации сохраняются. В обычном чате модель получает историю текущего диалога; сравнения выполняются независимо от неё.

Сравнение оформлено как в d22: слева ответ без rewrite/фильтра, справа — с ними. Длинные и многострочные ответы переносятся внутри столбцов по ширине терминала с учётом Unicode. Ниже показаны исходный вопрос, поисковая формулировка и источники обоих режимов.

Редактор и отрисовка перенесены из d22. Стрелки выбирают подсказку, Tab подставляет её, Enter выполняет готовую команду. Alt+Backspace удаляет слово, Shift+Enter или Ctrl+J добавляет строку. Колесо мыши прокручивает журнал; Alt+S переключает выделение текста мышью. Esc или Ctrl+C отменяет текущую операцию, повторное нажатие той же клавиши в течение секунды завершает программу. Курсор и строка ввода сохраняют положение при изменении размера окна.
