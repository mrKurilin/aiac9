# День 27 — локальная LLM в приложении

`mrkai` — работающее CLI-приложение: передаёт запросы локальному Ollama API, показывает ответы, время и число токенов и сохраняет историю в текущем сеансе. После `/reset` или `/clear` история очищается. Облачный API и ключи не нужны.

## Запуск

Нужны Go 1.21+, запущенная Ollama и загруженная `qwen3:4b-instruct`. Из каталога `aiac9/d27`:

```sh
ollama pull qwen3:4b-instruct
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
```

Модель по умолчанию — `qwen3:4b-instruct`. `OLLAMA_MODEL` и `OLLAMA_BASE_URL` позволяют изменить модель и адрес сервера. На Mac с 16 ГБ памяти начните с 4B; приложение ограничивает контекст 4096 и ответ 256 токенами.

## Команды

- `/model status` — локальные модели.
- `/check` — три тестовых вопроса.
- `/reset`, `/clear` — начать новый диалог.
- `/help`, `/exit`, `/quit` — справка и выход.

Обычный текст отправляется модели. Редактор поддерживает историю, Unicode, подсказки команд и отмену запроса по Esc или Ctrl+C.
