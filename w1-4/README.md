# w1-4 · LLM Playground (DeepSeek) — температура

Один и тот же запрос к LLM через API выполняется при `temperature = 0`, `0.7`, `1.2` и максимуме `2.0`, чтобы сравнить ответы по точности, креативности и разнообразию и понять, какая настройка для каких задач подходит.

## Запуск

```bash
export DEEPSEEK_API_KEY=sk-...
go run .
```

Откройте http://localhost:8080

## Что умеет

- Берёт **один промпт** (редактируется в верхнем поле) и отправляет его в DeepSeek API (модель `deepseek-chat`, OpenAI-совместимый формат) с четырьмя температурами, **параллельно**.
- **Сравнение в 4 колонках**: `temperature = 0` (точность), `0.7` (баланс), `1.2` (креативность) и `2.0` (максимум — верхняя граница диапазона DeepSeek).
- **Прогоны на температуру** (1–6, по умолчанию 3): каждая колонка выполняет промпт несколько раз, поэтому видно не только сам ответ, но и то, меняется ли он. Подсказка в колонке показывает, сколько ответов уникально, а сколько совпало.
- Ответы рендерятся как **Markdown**, формулы LaTeX (`\(…\)`, `\[…\]`, `$…$`, `$$…$$`) набираются через **KaTeX**.
- Внизу — краткий ориентир, для каких задач подходит каждая температура.

## Что сравнивать

| Ось            | Что смотреть                                                                                          |
|----------------|-------------------------------------------------------------------------------------------------------|
| Точность       | Тот же промпт на фактологическом вопросе: `0` даёт стабильный верный ответ, а `1.2`/`2.0` — возможные «фантазии» |
| Креативность   | Открытый промпт (нейминг, идеи, текст): `1.2` и `2.0` дают более неожиданные и выразительные формулировки     |
| Разнообразие   | Прогоны в одной колонке: на `0` ответы почти повторяются, с ростом температуры разброс увеличивается, у `2.0` ответы часто теряют связность |

## API сервера

- `GET /` — веб-интерфейс
- `POST /api/complete` — тело `{"prompt": "...", "params": {"temperature": 0.7}}`; `params` — произвольные параметры, мержатся поверх сформированного запроса; ответ `{"content": "...", "finish_reason": "...", "prompt_tokens": N, "completion_tokens": N, "total_tokens": N}` или `{"error": "..."}`

## Структура

- `main.go` — HTTP-сервер и прокси к DeepSeek
- `index.html` — веб-интерфейс (встроен в бинарник через `go:embed`); KaTeX подключён с CDN
