# День 26 — локальная LLM

`mrkai` — терминальный агент на локальной Ollama. По умолчанию используется компактная `qwen3:4b-instruct`, без облачного API и платных запросов. Команда `/check` выполняет три запроса разной сложности и показывает ответы, время и число токенов. Обычный ввод запускает диалог с памятью текущей сессии.

## Установка и запуск

Нужны Go 1.21+, Ollama и одна локальная чат-модель. Из каталога `aiac9/d26`:

```sh
ollama pull qwen3:4b-instruct
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
```

Ollama должна быть запущена локально. Если сервер находится на другом адресе, задайте `OLLAMA_BASE_URL`. Имя модели можно изменить через `OLLAMA_MODEL`. Приложение ничего не загружает автоматически. Модель `embeddinggemma` подходит для эмбеддингов, но не заменяет чат-модель.

## Команды

- `/model status` — показать загруженные модели и их размер.
- `/check` — выполнить три контрольных запроса.
- `/reset`, `/clear` — очистить историю диалога.
- `/help` — справка; `/exit`, `/quit` — выход.

Редактор терминала поддерживает историю, Unicode и автодополнение. Esc или Ctrl+C отменяет текущий запрос; повторное нажатие завершает программу. Начальные ограничения ответа: 256 токенов, контекст 4096 токенов. Это снижает расход памяти на Mac с 16 ГБ.
