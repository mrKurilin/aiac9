# Проектный файловый ассистент

Агент получает цель через `/task`, сам выбирает MCP инструменты `file_list`, `file_read`, `file_search` и `file_write`. Поиск охватывает Markdown, Go и TXT файлы. Запись разрешена только в Markdown внутри `docs/`: путь должен иметь расширение `.md` и лежать непосредственно в каталоге `docs`, а имя файла (как и имена всех сегментов пути) не должно начинаться с `.` и не должно содержать «чувствительных» слов (`secret`, `credential`, `password`, `token`, `private`, `apikey`, `api_key`), проверяемых через `safeDocName`. Это даёт воспроизводимые сценарии поиска использования API и обновления документации на основе кода.
