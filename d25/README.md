# День 25 — мини-чат с RAG и памятью задачи

`mrkai` — терминальный агент. Он сохраняет историю текущего диалога, ищет фрагменты в локальном индексе при **каждом** вопросе и выводит найденные источники после ответа. Отдельная память задачи хранит цель, уточнения, ограничения и значения терминов. Агент передаёт её модели вместе с историей; `/task status` показывает текущее состояние. Если нужного факта нет в документах, агент может запросить его у пользователя и использовать уточнение при составлении итогового документа; блок источников в этом случае сообщает, что документ не найден.

Индекс создаётся только по явной команде `/index build knowledge`. В `knowledge/` находятся четыре учебных документа проекта Mystical Machines `rag-explained`; условия использования — в `knowledge/LICENSE-rag-explained`. Индекс хранится в `data/index/`; `DATA_DIR` меняет каталог данных. `/reset` и `/clear` очищают историю и память, но сохраняют индекс.

## Установка и запуск

Нужен Go 1.21+. Из каталога `aiac9/d25`:

```sh
chmod +x mrkai
export PATH="$PWD:$PATH"
export DEEPSEEK_API_KEY=your_key_here
mrkai
```

Перед первым вопросом постройте индекс в терминале агента:

```text
/index build knowledge
```

Без индекса агент попросит выполнить эту команду; запуск `mrkai` сам документы не индексирует.

Дополнительные переменные: `DEEPSEEK_BASE_URL` для совместимого API и `DEEPSEEK_MODEL` для имени модели. Ключ передаётся только через окружение. Учебные документы англоязычные, поэтому для них лучше задавать вопросы на английском.

## Команды

- `/help` — список команд.
- `/index build [КАТАЛОГ]` — перестроить индекс по `.md` и `.txt` документам; без каталога берётся `knowledge`.
- `/index status` — число фрагментов.
- `/task status` — показать память задачи.
- `/task goal ТЕКСТ` — установить цель.
- `/task clarify ТЕКСТ` — добавить уточнение.
- `/task constraint ТЕКСТ` — добавить ограничение.
- `/task term НАЗВАНИЕ = ЗНАЧЕНИЕ` — зафиксировать термин.
- `/reset`, `/clear` — новый диалог; `/exit`, `/quit` — выход.

Например, задайте цель командой `/task goal Plan a CloudDrive rollout`, затем спросите `What is the maximum file size in CloudDrive?`. После нескольких уточнений проверьте `/task status`.

Редактор терминала поддерживает Unicode, историю ввода, многострочный текст, подсказки команд и выбор стрелками, Tab и Enter. Esc или Ctrl+C отменяет ввод либо выполняющийся запрос; повторное нажатие той же клавиши в течение секунды завершает программу.

Поиск использует локальные хеш-векторы слов, поэтому перефразирование на другом языке может не найти английский текст. Источники показывают найденные фрагменты; сами по себе они не гарантируют, что модель верно интерпретировала документ. При отсутствии подходящих фрагментов агент явно сообщает об этом.
