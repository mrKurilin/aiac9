# Необязательный Telegram-адаптер на VPS

Для обычного чата в терминале установка из этой папки не нужна: используйте `mrkai` из d35. Telegram использует ту же логику Agent и Aviasales, что и терминал.

Для VPS нужен полный checkout aiac9 (d35 и terminal рядом), Linux с systemd. Автоустановка Docker/Buildx поддерживает Ubuntu 24.04/26.04. Ориентир для личного бота: 1 vCPU, 1 ГБ RAM, 10 ГБ диска; нагрузочные испытания не проводились. Нужен исходящий HTTPS к Telegram, Travelpayouts, DeepSeek, а при сборке — к репозиториям Ubuntu и Docker. Входящие порты и домен не нужны.

Из d35 на VPS:

```sh
sudo bash deploy/bootstrap-vps.sh
```

Скрипт скрыто запросит три ключа: Telegram от @BotFather, Travelpayouts с программой Aviasales, DeepSeek. Затем — разрешённые числовые Telegram ID через запятую (Enter оставляет бота публичным). Запускается один контейнер mrkai-flights с long polling. После «Готово» отправьте боту /start. Проверяются Telegram и Aviasales; DeepSeek проверяется при первом платном запросе пользователя.

Команды бота: /start, /help, /reset, /clear, /cancel, /id. /id доступен без разрешения и показывает ID для настройки доступа. Бот отвечает только в личных чатах. До четырёх параллельных операций; один активный запрос на чат; интервал 10 секунд; до 40 запросов в день на пользователя и 500 на бота. Лимиты и история хранятся в памяти, сбрасываются при перезапуске; день по UTC. Сброс и отмена не обнуляют лимиты.

Повторный запуск установщика обновляет контейнер и снова запрашивает ключи. Предыдущий контейнер сохраняется до проверки нового; при неудачной проверке восстанавливается. Одновременно должен работать один экземпляр бота. Если есть webhook, используйте отдельного бота либо удалите его перед запуском.

```sh
sudo docker logs --tail 50 -f mrkai-flights
```

```sh
sudo docker restart mrkai-flights
```

```sh
sudo docker stop mrkai-flights
```

Ключи вводятся после сборки, временный файл с правами 600 удаляется; Docker хранит их в конфигурации контейнера, доступной администратору хоста. История в памяти, offset и heartbeat — в томе mrkai-flights-data. Ключи и тела ответов с ошибками не логируются. Диагностический trace.jsonl в томе сохраняет сообщения пользователей и успешные ответы для разбора. Переписка и условия передаются DeepSeek, параметры маршрута — Travelpayouts.

Контейнер запускается после перезагрузки, если не был остановлен вручную. Только статус unhealthy не перезапускает контейнер: временные сбои обрабатываются polling, фатальные завершают процесс и срабатывает restart policy. Фактические Docker-сборка и запуск на VPS должны проверяться на целевом сервере.
