# День 12 — персонализация ответов

MrKai показывает, как один и тот же вопрос меняется для трёх пользовательских
профилей:

- **Разработчик** получает компактный технический ответ, код, сложность и
  компромиссы;
- **Студент** получает пошаговое объяснение, бытовую аналогию и разбор примера;
- **Предприниматель** получает краткий бизнес-вывод без кода и лишнего жаргона.

Профиль пользователя — отдельная системная инструкция о стиле и формате ответа.
Он не является ролью сабагента и не хранится в долговременной памяти.
Автоматическая память содержит факты и решения, а профиль определяет, как эти
данные следует объяснять пользователю.

Веб-лаборатория отправляет общий вопрос трём независимым агентам параллельно и
показывает ответы в трёх колонках. У каждого профиля свои история диалога и
слои памяти, поэтому контекст между пользователями не смешивается.

## Установка и запуск

Нужны Go 1.21+ и ключ DeepSeek в окружении.

~~~sh
cd aiac9/d12
chmod +x mrkai
mkdir -p "$HOME/.local/bin"
ln -sf "$PWD/mrkai" "$HOME/.local/bin/mrkai"
export PATH="$HOME/.local/bin:$PATH"
export DEEPSEEK_API_KEY="<ваш-ключ>"
mrkai
~~~

Без аргументов запускается основной терминальный агент с профилем разработчика.
Из каталога дня также можно использовать ./mrkai.

Другой терминальный профиль выбирается перед запуском:

~~~sh
MRKAI_PROFILE=student mrkai
MRKAI_PROFILE=business mrkai
~~~

Сравнительный веб-интерфейс:

~~~sh
mrkai web
~~~

Откройте http://localhost:8080, выберите один из трёх готовых вопросов или
введите свой и нажмите «Отправить всем». Каждая колонка получает отдельный
потоковый ответ.

## Три демонстрационных запроса

1. «Объясни алгоритм Дейкстры и расскажи, когда его стоит использовать».
2. «Сравни быструю сортировку и сортировку слиянием. Как выбрать между ними?»
3. «Как работают рекомендательные алгоритмы и как понять, что они приносят
   пользу?»

Первый вопрос подчёркивает различия в глубине объяснения, второй — в способе
выбора и аргументации, третий — в технических, учебных и бизнес-акцентах.

## Терминальные команды

~~~text
/remember short|working|long KEY VALUE
/forget short|working|long KEY
/memory [short|working|long]
/clear short|working|long|all
/reset
/info
/exit
~~~

Профиль добавляется в каждый запрос автоматически. После успешного ответа
отдельный вызов модели извлекает атомарные факты и распределяет их по трём слоям
памяти. Просьбы о языке, длине, юморе и формате extractor не переносит в
долговременную память: эти настройки уже заданы явным профилем.

## Конфигурация

- DEEPSEEK_API_KEY — обязательный ключ;
- DEEPSEEK_MODEL — модель, по умолчанию deepseek-chat;
- DEEPSEEK_BASE_URL — OpenAI-совместимый endpoint DeepSeek;
- AGENT_SYSTEM_PROMPT — общая системная инструкция;
- MRKAI_PROFILE — профиль терминала: developer, student или business;
- DATA_DIR — каталог данных, по умолчанию ./data;
- WEB_ADDR — адрес веб-сервера, по умолчанию :8080;
- WEATHER_ENABLED — 1 по умолчанию, 0 отключает погоду;
- ARTICLES_ENABLED — 1 по умолчанию, 0 отключает рекомендации статей.

Память сохраняется раздельно под идентификаторами profile-developer,
profile-student и profile-business. Файлы создаются атомарно с правами 0600;
секреты и учётные данные сохранять нельзя.
