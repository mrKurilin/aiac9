# w1-1 · LLM Playground (DeepSeek)

Минимальный пример на Go: запрос к LLM через API с веб-интерфейсом для сравнения параметров генерации.

## Запуск

```bash
export DEEPSEEK_API_KEY=sk-...
go run .
```

Откройте http://localhost:8080

## Что умеет

- Отправляет промпт в DeepSeek API (модель `deepseek-chat`, OpenAI-совместимый формат).
- **Таблица сравнения**: для каждого параметра выполняются два запроса — значение «в минимум» и «в максимум» (остальные параметры — по умолчанию). Столбец «По умолчанию» считается один раз и повторяется во всех строках.
- **Кнопка ▼ слева по центру** — медленный автоскролл вниз; повторный клик останавливает.
- **Подсказки у каждого параметра**: что он делает и что будет на минимуме и максимуме.

## Параметры и допустимые диапазоны (DeepSeek)

| Параметр            | Диапазон | Примечание                                                  |
| ------------------- | -------- | ----------------------------------------------------------- |
| `temperature`       | 0–2      | 0 — «сухой», точный; 2 — максимум случайности               |
| `top_p`             | (0, 1]   | 0 недопустим (API вернёт ошибку)                            |
| `top_k`             | > 0      | не поддерживается DeepSeek; отправляется, только если задан |
| `max_tokens`        | ≥ 1      | лимит длины ответа                                          |
| `seed`              | 0–2³²−1  | 0 — не отправляется (случайность)                           |
| `presence_penalty`  | −2…2     | штраф за повтор темы, поощряет новизну                      |
| `frequency_penalty` | −2…2     | штраф за повторяющиеся слова                                |

## API сервера

- `GET /` — веб-интерфейс
- `POST /api/complete` — тело `{"prompt": "...", "params": {...}}`; ответ `{"content": "..."}` или `{"error": "..."}`

## Тесты

```bash
go test ./...
```

Герметичные тесты (`httptest`) — без сети и ключа API.

## Структура

- `main.go` — HTTP-сервер и прокси к DeepSeek
- `index.html` — веб-интерфейс (встроен в бинарник через `go:embed`)
- `main_test.go` — тесты
