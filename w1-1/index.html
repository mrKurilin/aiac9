DeepSeek API · сравнение ответов при параметрах «по умолчанию / минимум / максимум»

Для каждого параметра выполняются 2 запроса: настройка «в минимум» и «в максимум» (остальные — по умолчанию). Столбец «По умолчанию» считается один раз и повторяется во всех строках. top_k и seed при 0 не отправляются; top_k не поддерживается DeepSeek API.

Ответы модели

Столбец «По умолчанию» одинаков для всех строк — получен один раз с настройками по умолчанию.
