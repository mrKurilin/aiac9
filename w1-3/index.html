🎭 Способы рассуждения

DeepSeek API · одна задача решается четырьмя разными стратегиями — сравните ход мыслей и ответы.

Четыре запроса запускаются параллельно: прямой ответ, «решай пошагово», сначала составление промпта, группа экспертов.

Сравнение способов

В каждой колонке — что реально отправлено в API и ответ модели.
1
Без подсказок
В API уходит только условие задачи — прямой ответ модели.
2
«Решай пошагово»
К условию дописывается инструкция решать пошагово и объяснять каждый шаг.
3
Сначала промпт — потом решение
Модель сначала составляет промпт для решения задачи, затем решает по нему. Два запроса.
4
Группа экспертов
В одном промпте создаётся группа из аналитика, инженера и критика — решение от каждого плюс итог.
