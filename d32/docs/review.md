# Архитектура ревью

Команда `/review` собирает список изменённых файлов и diff через git. Локальный RAG индексирует README, Markdown документацию и Go исходники. Агент передаёт модели diff и найденные фрагменты и возвращает Markdown ревью. Workflow вызывает тот же режим через `--review` и добавляет результат в комментарий к PR.
