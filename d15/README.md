# День 15 — контролируемый жизненный цикл задачи

MrKai ведёт задачу через конечный автомат `planning → execution → validation → done`.
Модель может только предложить переход, а решение принимает Go-код по фиксированному
графу и контрольным условиям. Поэтому нельзя начать реализацию без утверждения
плана, перейти к проверке до завершения реализации или закончить задачу без явно
успешной валидации.

Состояние, контрольные отметки, история диалога и журнал разрешённых и отклонённых
переходов сохраняются в `data/task-state.json`. После `/pause`, выхода и нового
запуска `/resume` продолжает ровно с сохранённого этапа. Инварианты из d14 также
сохранены и лежат отдельно в `data/invariants.json`.

## Установка и запуск

Нужны Go 1.21+ и ключ DeepSeek в окружении.

~~~sh
cd d15
chmod +x mrkai
export PATH="$PWD:$PATH"
export DEEPSEEK_API_KEY="<ваш-ключ>"
mrkai
~~~

Настройка `PATH` действует в текущем сеансе терминала и оставляет установку
самодостаточной внутри каталога дня. Из него также доступен `./mrkai`. Основной
интерфейс — терминальный; параметры запуска и demo-режимы не используются.

## Жизненный цикл

Разрешены только переходы:

~~~text
planning   → execution
execution  → validation | planning
validation → done | execution
done       → —
~~~

У продвижения есть независимые предусловия:

- `planning → execution` требует явного утверждения плана пользователем;
- `execution → validation` требует завершённой реализации;
- `validation → done` требует явного сообщения об успешных проверках.

Команда `/state` показывает этап, текущий шаг, три контрольные отметки и журнал
переходов. Запрещённая попытка получает `outcome: rejected`, не меняет этап и
остаётся видимой после перезапуска. Возврат на предыдущий этап сбрасывает
устаревшие отметки, чтобы новый вариант снова прошёл нужные проверки.

## Команды

~~~text
/state
/invariants
/invariant add КАТЕГОРИЯ | ПРАВИЛО
/invariant remove ID
/invariant clear
/pause [ПРИЧИНА]
/resume
/reset
/info
/exit
~~~

Обычным сообщением опишите задачу. Агент создаст её в `planning`, предложит план
и попросит утверждение. Попытку пропустить этап можно сделать обычной фразой —
контроллер отклонит её и объяснит недостающее условие.

## Конфигурация

- `DEEPSEEK_API_KEY` — обязательный ключ;
- `DEEPSEEK_MODEL` — модель, по умолчанию `deepseek-chat`;
- `DEEPSEEK_BASE_URL` — OpenAI-совместимый endpoint DeepSeek;
- `AGENT_SYSTEM_PROMPT` — общая системная инструкция;
- `DATA_DIR` — каталог данных, по умолчанию `./data`;
- `INVARIANTS_FILE` — отдельный путь к JSON с инвариантами.

Не вводите в задачу, инварианты и команды ключи, пароли и другие секреты.
