# День 29 — оптимизация локальной LLM

`mrkai` сравнивает базовый и экономный профили одной `qwen3:4b-instruct`. Экономный профиль используется по умолчанию: temperature 0.2, максимум 256 токенов ответа, контекст 4096 и короткий prompt-шаблон. Базовый профиль: 0.7, 512 токенов, 8192 контекста. `/benchmark ВОПРОС` показывает оба ответа рядом, время, токены, объём модели в памяти по Ollama и источники RAG; качество можно оценить по тексту и источникам.

## Запуск

Нужны Go 1.21+, Ollama, `qwen3:4b-instruct` и `embeddinggemma`. Из каталога `aiac9/d29`:

```sh
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
```

Для первого построения индекса выполните `/index build knowledge`. Команда читает `.md` и `.txt` файлы из каталога, переданного пользователем. Чтобы не тратить ресурсы повторно, индекс сохраняется в `data/index.json` (`DATA_DIR` меняет расположение).

## Команды

- `/profile status` — текущие параметры.
- `/profile baseline`, `/profile optimized` — выбрать профиль.
- `/benchmark ВОПРОС` — сравнить ответы, скорость и память на одном вопросе.
- `/index build [КАТАЛОГ]`, `/index status` — индекс RAG.
- `/model status` — в том числе уровень квантования загруженной модели.
- `/reset`, `/clear`, `/help`, `/exit`, `/quit` — управление диалогом.

`qwen3:4b-instruct` уже поставляется в компактном варианте Q4. Для задания не требуется скачивать 8B или вторую копию 4B. Если понадобится сравнение разных уровней квантования, можно отдельно загрузить вариант Q8 той же 4B-модели и указать его через `OLLAMA_MODEL`; это потребует дополнительного места и памяти.
