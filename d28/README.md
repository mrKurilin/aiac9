# День 28 — локальная LLM и RAG

`mrkai` ищет фрагменты документов через локальные эмбеддинги `embeddinggemma` и генерирует ответ через локальную `qwen3:4b-instruct`. Индекс создаётся по явной команде и хранится в `data/index.json`; повторный запуск не требует пересчёта. Ответ сопровождается названиями использованных файлов.

## Запуск

Нужны Go 1.21+ и запущенная Ollama. Из каталога `aiac9/d28`:

```sh
ollama pull qwen3:4b-instruct
ollama pull embeddinggemma
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
```

`embeddinggemma` уже установлена на текущем Mac; повторно загружать её не нужно. Приложение само модели не скачивает. Переменные `OLLAMA_MODEL`, `OLLAMA_EMBED_MODEL`, `OLLAMA_BASE_URL` и `DATA_DIR` меняют модель, адрес и каталог индекса.

## Команды

- `/index build [КАТАЛОГ]` — построить локальный индекс; по умолчанию `knowledge`.
- `/index status` — показать число фрагментов.
- `/model status` — модели Ollama.
- `/check` — три запроса без RAG для проверки генерации.
- `/reset`, `/clear` — очистить историю беседы, сохранив индекс.
- `/help`, `/exit`, `/quit` — справка и выход.

После `/index build knowledge` задайте вопрос обычным текстом. Файлы более 1 МиБ, скрытые файлы и файлы с чувствительными именами не индексируются. Длина контекста ограничена 4096 токенами, ответ — 256 токенами для экономии памяти.
