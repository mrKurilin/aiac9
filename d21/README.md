# День 21 — локальная индексация документов

MrKai строит два индекса по документации и коду: разбиение на фрагменты по 180 слов с перекрытием 30 слов и разбиение по заголовкам Markdown или объявлениям Go. Длинные разделы также делятся по 180 слов. У каждого фрагмента есть источник, имя файла, раздел, идентификатор, текст и 384-мерный вектор. Индексы сохраняются в JSON, а команда сравнения показывает число фрагментов и лучшие совпадения по одному запросу.

Векторы рассчитываются локально из частот слов с хешированием и нормализацией. Это воспроизводимые эмбеддинги для учебного пайплайна, без предобученной семантической модели и без сетевых запросов. Совпадение определяется косинусной близостью; смысловые синонимы без общих слов могут не найтись.

## Установка и запуск

Нужен Go 1.21+. В каталоге `aiac9/d21`:

```sh
export PATH="$PWD:$PATH"
mrkai
```

`mrkai` запускает терминальный чат. Планирование включается командой `/plan-mode enable`. Для обычного диалога укажите `DEEPSEEK_API_KEY`; локальная индексация и прямые команды MCP работают без него. Для повышенных лимитов GitHub задайте `GITHUB_TOKEN` в окружении до запуска `mrkai`. Токен передаётся GitHub API в заголовке `Authorization`; без него остаётся анонимный режим. При необходимости задайте `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL`, `AGENT_SYSTEM_PROMPT`, `GITLAB_API_TOKEN`, `GITLAB_API_URL`, `KNOWLEDGE_DIR`, `DATA_DIR`, `INVARIANTS_FILE`. Ключи задаются через переменные окружения, без файлов в проекте.

Чтобы агент сам собрал корпус, напишите ему: «Найди публичные GitHub-репозитории по теме vector databases, скачай их README и построй оба индекса». Агент вызовет инструмент `index_github_readmes`; для такого запроса нужен `DEEPSEEK_API_KEY`. Без ключа модели ту же операцию выполняет `/index github vector databases`. Поиск GitHub сортируется по числу звёзд по убыванию, а итоговый список показывает число звёзд каждого проекта. Скачиваются README максимум 40 публичных репозиториев или до достижения 10 000 слов. Если объём меньше учебной цели, команда сообщает об этом. README сохраняются в `DATA_DIR/github-readmes`, индексы — в `DATA_DIR/index`. GitHub API ограничивает число запросов без авторизации; ошибки HTTP показываются без содержимого ответа.

Если указать число в запросе к агенту, например «Найди 35 репозиториев по теме vector databases и проиндексируй их README», агент передаст его инструменту и продолжит загрузку до указанного числа даже после достижения 10 000 слов. Максимум — 40. Если доступных README меньше, результат покажет фактическое число.

GitHub может вернуть README как обычный текст или как JSON с содержимым в base64; поддерживаются оба варианта. Отсутствующий README и файл с неподдерживаемым форматом пропускаются. Поэтому запрос на 35 репозиториев может завершиться, например, с 30 проиндексированными README; фактическое число будет указано в результате.

По умолчанию `/index build` читает текущий каталог: обычные `.go`, `.md`, `.txt` файлы, исключая скрытые каталоги, `data`, тесты Go и имена, похожие на файлы с секретами. Отдельный файл ограничен 512 КиБ, весь корпус — 32 МиБ. Индексы записываются в `DATA_DIR/index/fixed.json` и `DATA_DIR/index/structure.json` (по умолчанию `./data/index`). Для другого корпуса используйте `/index build КАТАЛОГ`. PDF напрямую не разбирается: сначала преобразуйте его в `.txt`.

## Команды

- `/index build [КАТАЛОГ]` — построить оба индекса.
- `/index github ТЕМА` — найти популярные публичные репозитории по теме, скачать README и построить оба индекса.
- `/index status` — показать состояние и число документов, слов, фрагментов.
- `/index search fixed ЗАПРОС` и `/index search structure ЗАПРОС` — найти пять ближайших фрагментов.
- `/index compare ЗАПРОС` — сравнить число фрагментов и три лучших результата обеих стратегий.
- `/mcp`, `/mcp list`, `/mcp mrkgitlab tools`, `/mcp mrkgitlab mrs [ПРОЕКТ]`, `/mcp mrkgitlab call NAME JSON` — серверы и GitLab.
- `/mcp mrkpipeline tools`, `/mcp mrkpipeline run ЗАПРОС | ФАЙЛ.md`, `/mcp mrkpipeline call NAME JSON` — поиск документов и отчёты.
- `/mcp mrkscheduler tools`, `/mcp mrkscheduler add СЕКУНДЫ ПЕРИОД ТЕКСТ`, `/mcp mrkscheduler mrs СЕКУНДЫ [ПРОЕКТ]`, `/mcp mrkscheduler list`, `/mcp mrkscheduler summary`, `/mcp mrkscheduler cancel ID` — напоминания.
- `/plan-mode enable`, `/plan-mode disable`, `/state`, `/pause`, `/resume`, `/reset` — режим задачи.
- `/invariants`, `/invariant add КАТЕГОРИЯ | ПРАВИЛО`, `/invariant remove ID`, `/invariant clear` — инварианты.
- `/info`, `/help`, `/exit`, `/quit` — справка и выход.

Команды и подкоманды доступны через автодополнение. Во время построения индекса терминал показывает чтение файлов, стратегию, количество фрагментов и путь сохранения. Остальные возможности агента унаследованы от d20; подключённые MCP-инструменты доступны модели после обнаружения схем.
