# День 16 — подключение MCP

MrKai запускается в терминале, устанавливает локальное MCP-соединение через stdio,
пишет runtime-лог запуска и возможностей сервера, затем выводит список инструментов.
Команда `/tools` повторно запрашивает список.
Локальный сервер предоставляет инструменты `echo` и `uppercase`; их описания и
схемы параметров передаются стандартным ответом `tools/list`, а вызвать их можно
командой `/mcp call NAME ТЕКСТ`. Агент сохраняет поведение d15:
этапы задачи, инварианты, паузу и восстановление.

## Установка и запуск

Нужен Go 1.21+.

~~~sh
cd aiac9/d16
chmod +x mrkai
export PATH="$PWD:$PATH"
mrkai
~~~

Из каталога дня можно также запустить `./mrkai`. При старте появятся сообщения
`[MCP] Сервер запущен`, о завершённом `initialize`, поддержке `tools/list` и
`tools/call`, а затем список инструментов. Для знакомства с MCP ключ модели
не требуется. Для обычного диалога с агентом задайте `DEEPSEEK_API_KEY` в окружении:

~~~sh
export DEEPSEEK_API_KEY="<ваш-ключ>"
mrkai
~~~

## Команды

`/tools` и `/mcp list` — обновить список инструментов MCP; `/mcp call echo Привет`
повторяет текст, `/mcp call uppercase Привет` переводит его в верхний регистр.
`/state` — состояние задачи;
`/invariants` и `/invariant add|remove|clear` — инварианты; `/pause`, `/resume`,
`/reset`, `/info`, `/exit` — управление сессией. Обычное сообщение передаётся
агенту и требует ключа модели.

## Конфигурация

`DEEPSEEK_API_KEY` — ключ для диалога; `DEEPSEEK_MODEL` — модель (по умолчанию
`deepseek-chat`); `DEEPSEEK_BASE_URL` — адрес совместимого API;
`AGENT_SYSTEM_PROMPT` — системная инструкция; `DATA_DIR` — каталог состояния;
`INVARIANTS_FILE` — файл инвариантов. MCP-сервер запускается как дочерний процесс
того же приложения и не требует сетевого адреса.
