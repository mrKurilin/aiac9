# Справочник MrKai для проверки RAG

## Запуск
Команда mrkai запускает терминальный агент по умолчанию. Для обычного диалога с моделью нужен DEEPSEEK_API_KEY.

## Планирование
Режим планирования включается командой /plan-mode enable. По умолчанию работает обычный чат.

## Локальный индекс
Команда /index build строит индексы fixed и structure. Первый режет текст по 180 слов с перекрытием 30 слов, второй по заголовкам и объявлениям.

## Векторы
Локальные эмбеддинги имеют 384 измерения. Они считаются хешированием частот слов без предобученной семантической модели.

## Поиск
Команда /index search structure ЗАПРОС находит пять ближайших чанков. Сходство измеряется косинусной близостью.

## GitHub README
Команда /index github ТЕМА скачивает README публичных репозиториев. Предел составляет 40 репозиториев или 10000 слов, если не запрошено конкретное число.

## Хранилище
Индексы сохраняются в DATA_DIR/index/fixed.json и DATA_DIR/index/structure.json. По умолчанию DATA_DIR равен ./data.

## MCP
Инструменты MCP обнаруживаются после подключения сервера. Агент передаёт модели схемы инструментов и возвращает результаты вызовов в её контекст.

## Инварианты
Команда /invariant add КАТЕГОРИЯ | ПРАВИЛО сохраняет инвариант. Команда /invariants показывает текущий список.

## Остановка
Ctrl+C или Esc останавливает текущее выполнение. Двойное нажатие завершает mrkai.
