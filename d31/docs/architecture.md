# Устройство ассистента d31

Терминальный пакет `aiac9/terminal` обрабатывает ввод, автодополнение, историю и отмену операций. `main.go` связывает команды с агентом. `agent.go` хранит историю диалога и вызывает DeepSeek совместимый HTTP API. `rag.go` строит локальный поисковый индекс из README и Markdown файлов папки docs. `mcp.go` подключает локальный MCP сервер проекта через stdio и предоставляет модели инструмент `git_branch`.

Команда `/help ВОПРОС` ищет фрагменты документации и передаёт их модели с указанием источников. Модель может вызвать MCP инструмент для текущей ветки. `/mcp git branch` вызывает тот же инструмент вручную. Индекс сохраняется в `data/index.json`. `/reset` и `/clear` очищают историю диалога, но сохраняют индекс и исходные документы.
