# День 31 — ассистент разработчика

Терминальный агент отвечает на вопросы о структуре проекта по README и файлам `docs/` через локальный RAG индекс. Через MCP он узнаёт текущую git ветку. Обычный ввод — многоходовой чат; консультация по проекту включается командой `/help ВОПРОС`.

## Установка и запуск

Нужен Go 1.21+ и ключ DeepSeek совместимого API. Из `aiac9/d31`:

```sh
chmod +x mrkai
export PATH="$PWD:$PATH"
export DEEPSEEK_API_KEY=YOUR_API_KEY
mrkai
```

По умолчанию индексируется этот каталог. Для другого проекта задайте `MRKAI_PROJECT_ROOT` — абсолютный путь к каталогу с `README.md` и `docs/`. `DEEPSEEK_BASE_URL` (по умолчанию `https://api.deepseek.com/chat/completions`) и `DEEPSEEK_MODEL` (по умолчанию `deepseek-chat`) позволяют выбрать совместимый API. Индекс сохраняется в каталоге `data/` рядом с `mrkai`; сменив проект, выполните `/index build`. Ключ задаётся только переменной окружения.

## Команды

- `/help` — подсказка по командам; `/help ВОПРОС` — ответ по документации и контексту проекта.
- `/index build` — перестроить индекс README и `docs/`; `/index status` — показать число фрагментов.
- `/mcp tools` — список инструментов MCP; `/mcp git branch` — текущая git ветка.
- `/reset`, `/clear` — новый диалог без удаления индекса.
- `/exit`, `/quit` — выход.

Индекс создаётся при первом проектном вопросе, если его ещё нет. Индексируются только `README.md` и обычные `.md` файлы внутри `docs/`; скрытые файлы, ссылки и файлы с секретными именами пропускаются. Ответ `/help` указывает использованные источники. Для офлайн проверки подходит `go test ./...`; тесты не вызывают платный API.
